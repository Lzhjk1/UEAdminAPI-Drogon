# 资源市场（Beta）

> 状态：Beta（2026-11-21 上线；2026-11-22 支持多类型、官方库包与关联标准）
> 入口：UE AI CAD 工作台 → 资源市场（侧栏工作区）
> 服务端实现：`controllers/MarketController.*`、`services/MarketService.*`、迁移 `db/migrations/0022_market_resource.sql`、`0027_market_kinds_official.sql`

## 是什么

登录用户上传、分享、下载**元件库**、**等级库**、**设计库**与**标准库**文件包（Jet 数据库 `.mdb` / `.db` 或打包 `.zip`）。一个文件可同时属于多个类型（如同时含等级库与元件库）。上传即发布，所有登录用户可见可下载；上传者可随时删除自己的资源，管理员可删除任意资源。当前为 Beta，目录与字段可能调整。

## 接口

全部接口需要 `Authorization: Bearer <token>`（AuthFilter）；响应统一为 `{code, msg, data}`，HTTP 恒为 200，`code=0` 表示成功。

| 方法与路径 | 用途 | 说明 |
|---|---|---|
| `GET /api/market/resources` | 资源列表 | 查询参数 `category=component\|spec\|design\|standard`（按包含的类型过滤）、`keyword`、`page`、`pageSize`（≤200）；返回 `items`、`total`、`counts`（四类计数）、`beta`；每条含 `kinds`、`official`、`standardCode` |
| `POST /api/market/resources/upload/init` | 创建上传会话 | JSON：`name`、`version`、`description`、`kinds`（数组，至少一个）、`fileName`、`fileSize`；兼容旧的 `category` 单值；返回 `uploadId`、`chunkSize`（4 MB） |
| `POST /api/market/resources/upload/{id}/chunk?offset=` | 写入分片 | 原始字节体（`Content-Type: application/octet-stream`），offset 必须等于服务端已写入字节数；不一致会返回当前 offset 供重同步 |
| `POST /api/market/resources/upload/{id}/complete` | 完成上传 | 校验文件大小与 sha256，落盘并生成资源记录；重复调用幂等 |
| `PATCH /api/market/resources/{id}/kinds` | 回填类型标签 | JSON：`kinds` 数组；导入工程标准时客户端探测 Spec/CATA/DESI 表后调用，覆盖旧标签 |
| `PATCH /api/market/resources/{id}/meta` | 设置官方库包 | JSON：`official`（布尔）、`standardCode`（关联内置标准编号，如 `GB/T 17116`）；仅管理员（Admin 位 / `super_admin`） |
| `GET /api/market/resources/{id}/download` | 下载 | 文件流，`Content-Disposition` 带原文件名；同时下载次数 +1 |
| `DELETE /api/market/resources/{id}` | 删除 | 仅上传者本人或管理员；软删（`status=0`）并移除磁盘文件 |

## 限制与约定

- 文件类型：`.mdb` / `.db` / `.zip`；单文件 ≤ 200 MB。
- 分片：4 MB/片，单请求 ≤ 8 MB；会话 24 小时未更新自动清理。
- 存储：`Market.StoreDir`（默认 `./market`）/ `<resource_id>/<file_name>`；临时文件 `Market.UploadTempDir`（默认 `./uploads/market-tmp`）。
- 表：`market_resource`（资源与下载计数，`kinds text[]`、`official`、`standard_code`）、`market_upload_session`（分片会话）。
- 上传者是普通成员即可，不需要管理员权限；列表对全平台可见（不按团队隔离）。
- `kinds` 取值：`component` 元件库 / `spec` 等级库 / `design` 设计库 / `standard` 标准库；`category` 列保留为 `kinds[0]`，兼容旧客户端。

## 客户端

工作台页面：`ue-ai-cad/assets/market.js`、`market.css`；桥接口：`bridge/server.py` 的 `/api/market/*`（包含列表、分片转发、后台下载与进度、打开所在文件夹、删除、导入为工程标准）。
下载文件保存到 `%LOCALAPPDATA%\UE AI CAD\资源市场\`，完成后可在卡片上打开所在文件夹，或直接「导入为工程标准」（导入时探测库表结构并回填类型标签）。

## 已知问题与修复记录

- 2026-11-21：`LIMIT/OFFSET` 需显式 `::int`（Drogon 参数绑定），已修。
- 2026-11-21：`fileSize` 以前端 JSON 数字传入，控制器只读字符串导致读成 0，已支持数字与字符串。
- 2026-11-21：计数查询参数编号与列表不同（`$1/$2`），不能复用带 `$1=userId` 的过滤串，已独立编号。
- 2026-11-22：`category` 单选升级为 `kinds` 多值；旧数据按原 category 回填，导入时由客户端按库表结构覆盖。
