# 新用户试用与 Free 降级

2026-11-19 起，自助注册的新用户自动获得 30 天试用；2026-11-20 起，试用/订阅到期**不再拒绝登录**，而是允许进入 Free 版：客户端读取 `/api/me/bootstrap` 的 `subscription.active=false`，按功能开关暂停 AI 对话、Agent 批量出图、云工程与团队子账号，基础 CAD 设计、本地工程和在线更新继续可用。订阅套餐尚未在自助渠道发布，开通/续费仍由销售在后台设置。

## 1. 试用规则

| 项目 | 规则 |
| :--- | :--- |
| 适用对象 | 自助注册（邮箱 / 手机 / 第三方首次注册）创建的个人团队 |
| 试用天数 | `Subscription.TrialDays`，默认 30 天 |
| 起止日期 | `start_date` = 注册当天（北京时间）；`end_date` = 注册当天 + 29 天，**含注册当天共 30 天** |
| 到期判定 | 按北京时间自然日；`end_date` 当天仍可用，次日起到期 |
| 试用功能 | 自动开通 `cloud_project`（云工程）与 `online_update`（在线更新），与付费用户一致 |
| 存量用户 | 试用上线前注册、没有订阅记录的用户**不追溯、不拦截**；已有订阅记录但已过期的仍会拦截 |
| 充值 | 充值只入余额，**不自动解锁或续期**；开通统一由销售设置正式订阅 |
| 豁免账号 | 厂商团队（`team.is_vendor=true`）、`privilege` 的 Admin 位、系统角色 `super_admin` |

试用与正式订阅共用 `team_subscription` 表：

- `is_trial=true`：注册赠送的试用期，`plan='trial'`；
- `is_trial=false`：销售设置的正式订阅/历史付费记录；
- 当前生效记录仍取 `status=1` 中 `end_date` 最大的一条。

## 2. 到期降级（Free）

所有登录路径（密码、邮箱/手机验证码、微信/QQ、OAuth2 设备登录、FlashToken）在订阅到期后仍可签发 Token，不再返回 `-808`。到期状态由登录后的聚合接口返回：

```json
{
  "subscription": {
    "startDate": "2026-11-19",
    "endDate": "2026-12-18",
    "active": false,
    "plan": "trial",
    "isTrial": true,
    "remainingDays": -1
  }
}
```

客户端/网关按以下规则降级为 Free：

| 能力 | Free |
| :--- | :--- |
| 基础 CAD 设计 / 绘图（随原 CAD 授权） | 可用 |
| 本地工程打开 / 保存 | 可用 |
| 在线更新 | 可用（`online_update` 授权为 true 时） |
| AI 对话 / Agent 批量出图 | 暂停 |
| 云工程上传 / 协同 | 暂停；已有云工程只读/可下载 |
| 团队子账号 | 暂停；保留 1 个管理员 |

`-808`（`ApiError_UserNotPaid`）仍保留给需要付费授权的云端能力（如云工程/在线更新的额外授权）；登录链路不再使用。已签发的旧 Token 不会立即吊销，最长在 `UserManage.tokenExpeirSec`（默认 720 秒）后自然失效。

## 3. 配置

```yaml
custom_config:
  Subscription:
    TrialDays: 30
    TrialExpiredMessage: "试用期已结束，请联系销售开通：0731-88808590 / 19918074079（微信同号）"
    ExpiredMessage: "团队订阅已到期，请联系销售续费：0731-88808590 / 19918074079（微信同号）"
```

- 配置缺失时代码使用同样的默认值，不需要改库；
- 修改提示语只需改 `config.yaml` 并重启服务。

## 4. 销售开通/续费

1. 查看到期团队：`GET /api/admin/teams?expired=1`；
2. 查看团队详情：`GET /api/admin/teams/{teamId}`，`subscription.plan` / `isTrial` / `endDate` 可区分试用与正式订阅；
3. 设置付费期：`PUT /api/admin/teams/{teamId}/subscription`，Body：

```json
{ "startDate": "2026-11-19", "endDate": "2027-11-18", "plan": "standard" }
```

该接口写入的是正式订阅（`is_trial=false`）。试用期内提前开通也按同一接口处理，生效记录自动取 `end_date` 更大的一条。

## 5. 套餐席位（2026-11-20）

| 套餐 | 席位上限 | 说明 |
| :--- | :---: | :--- |
| trial / plus | 4 | 1 管理员 + 3 成员 |
| pro / standard / legacy | 10 | 标准团队 |
| max | 30 | 设计院部门 |
| Free（AI 订阅到期且无 PDMS） | 1 | 仅保留管理员 |
| PDMS-only / AI 到期 + PDMS 有效 | 不限 | PDMS 客户保留团队账号 |
| 厂商团队 | 不限 | 用于跨团队建号/支持 |
| 无订阅记录的存量团队 | 不限 | 迁移前保持原状 |

`TeamService::CreateMember` / `CreateMemberInTeam` 在创建成员前按团队当前订阅计算上限；超过时返回“团队席位已满（已用/上限），请升级套餐或增购席位”。移除成员/停用成员会释放席位。

## 6. 双产品订阅（PDMS / UEAICAD，2026-11-20）

`team_subscription` 增加 `product`：`pdms`（传统套件，网络授权，¥80,000/团队/年，不限节点）与 `ueaicad`（AI 工作台加购，沿用 Plus ¥9,800 / Pro ¥24,800 / Max ¥49,800；打包总价 ¥89,800 / ¥104,800 / ¥129,800）。存量记录已回填 `ueaicad`。

- **权限**：UEAICAD 订阅自动包含 PDMS（`products.pdms.source="implied"`）；PDMS-only 不获得 AI/平台功能；两者都允许单独存在（PDMS-only 由销售用 `product=pdms` 开通）。
- **`subscription` 字段固定为 UEAICAD 视图**；PDMS 记录不会进入 AI 套餐/剩余天数。bootstrap/团队/后台详情另返回 `hasSubscriptionRecord` 与 `products{pdms,ueaicad}`（`source`: subscription / implied / vendor / legacy / none）。
- **席位**：只有有效 UEAICAD 订阅按套餐限制；PDMS-only 或“AI 到期 + PDMS 有效”不限；纯 AI 到期仍为 1 席。
- **试用**：30 天全功能 = UEAICAD `trial`，因此含 PDMS；若后续不赠送 PDMS，只需调整产品推导。
- **存量**：零订阅记录团队继续按存量授权（Pro 级 AI + PDMS + 不限席位）；商业基线确认后再按合同到期日补记录。
- **厂商**：厂商超管直通 Max，两个产品均有效。
- **后台**：`PUT /api/admin/teams/{id}/subscription` 增加可选 `product`（默认 `ueaicad`，非法值 `-820`）；列表返回 `pdmsActive`，详情返回完整 `products`。

## 7. 已知边界

- 登录链路已不再拦截到期用户；Free 功能限制由客户端/工作台按 `subscription.active` 与功能开关执行。当前客户端启动界面还提供局域网登录、直接进 CAD、直接进管理入口，这些路径不经过本服务；如果产品要求“Free 也不可用 AI”，需要在客户端增加启动/命令闸门或收紧启动方式。
- 厂商在团队内直接创建的账号不单独发试用，在团队内时随团队订阅；被移出并新建个人团队后没有订阅记录，按存量用户口径放行。若后续要收紧，可增加“账号创建时间切点”或给新建个人团队补一条到期记录。
- 订阅套餐发布后，只需在充值/购买成功后写入同一张 `team_subscription`（`is_trial=false`），登录拦截逻辑无需再改。
